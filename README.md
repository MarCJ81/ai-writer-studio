# 원탭 원고 스튜디오 (One-Tap Draft Studio)

주제 한 줄과 경험 메모 2~3줄로 **네이버 블로그 원고 · 스레드 타래 · 상세페이지 카피**를 조립하는 정적 웹앱입니다.
API 키 없이 100% 무료로 초안이 나오고, 유료 API(또는 자체 서버)를 연결하면 2,000자 이상 완성 원고를 바로 받습니다.

- 서버 없음 · 회원가입 없음 · 결제 없음
- 무료 모드에서 외부 요청 0건
- AI 티 · 표시광고법 위험 · 도달 저하 표현 실시간 점검

## 디자인 (A안 · Crisp Bento)

`data-design="designref.v2/crisp-bento"`. 핀터레스트 리서치의 A안 토큰을 그대로 씁니다.

| 항목 | 값 |
|---|---|
| 배경 / 타일 / 보조 타일 | `#FAFAFA` / `#FFFFFF` / `#F5F6F7` |
| 잉크 / 본문 보조 / 라벨 | `#0C0D0F` / `#4A4F55` / `#6B7076` |
| 보더 / 라운드 | 1px `#E7E8EA` / 카드 16 · 버튼 12 · 필 999 |
| 액센트(단일) | 코발트 `#2F5BFF` |
| 헤드라인 | 산세리프(PlexKR) **800**, 자간 `-.045em` |

- 입력 화면은 **타일 벤토**(포맷 · 주제 · 경험 · 말투)로 쪼개고, 결과 화면은 제목·편집기·구조·점검을 각각 타일로 올렸습니다.
- 라이트/다크 모두 실제 렌더 텍스트 전수 대비 검사(4.5:1) 통과. 다크는 같은 토큰의 잉크 팔레트입니다.
- hover에서만 그림자, `prefers-reduced-motion` · `prefers-reduced-transparency` · `forced-colors` 대응.

## 무엇을 만드나

| 포맷 | 산출물 | 기준 |
|---|---|---|
| 네이버 블로그 | 제목 5안 · 도입 훅 · 소제목 5단 · 체크리스트 5항목 · 비교표 · 사진 5~6곳 · 끝 질문 | 공백 제외 2,200자 목표, 실사 사진, 내부링크 2건 |
| 스레드·인스타 | 250자 훅 · 2~4부 타래 · 마무리 · 자기 첫 댓글 · 캡처 1장 위치 | 첫 줄 250자, 본문 링크 0건, 끝에 질문 |
| 상세페이지·세일즈 | 헤드라인 5안 · 7단 설득 구조(문제→원인→해결→증거→차별점→리스크 리버설→CTA) | 900~1,500자, 최상급·보장 금지, 환불 조건은 실제 정책만 |

말투는 3종입니다. **말하듯 구어체**(해요체, 스레드는 반말) · **전문가 정보형**(합니다체) · **솔직 후기형**(실패담 먼저).
같은 입력에서 `다른 구성`을 누르면 문장 선택이 바뀌고, 같은 seed에서는 항상 같은 결과가 나옵니다.

## 두 가지 모드

### 무료 모드 (기본)
1. 포맷 · 주제 · 독자 · 경험 메모 · 말투를 입력합니다.
2. `무료로 초안 조립`을 누르면 문단 구조와 경험 슬롯이 채워진 초안이 나옵니다(블로그 1,400자 안팎).
3. `AI 티 다듬기`는 규칙으로 바꿀 수 있는 표현만 자동 교정합니다(사실·수치는 건드리지 않음).
4. 본문은 그대로 복사하거나, Markdown · HTML · 텍스트 형식으로 복사·저장할 수 있습니다.
5. `AI 브리지`에서 프롬프트를 복사해 ChatGPT·Claude·Gemini에 붙여넣고, 받은 원고를 다시 가져오면 점검이 재계산됩니다.

### Pro 모드 (선택)
`Pro 연결` 화면에서 네 곳 중 하나를 고릅니다. **1 OpenAI · 2 Google Gemini · 3 Anthropic Claude · 4 자체 API 서버(커스텀 프록시)**.
키를 넣고 `Pro로 원고 뽑기`를 누르면 완성 원고가 편집기에 들어가고, 곧바로 점검이 다시 돌아갑니다.

- 키는 기본적으로 `sessionStorage`(탭 메모리, 키 이름 `proconnector.config.v1`)에만 저장됩니다. 창을 닫으면 사라집니다.
- `연결 지우기`로 즉시 삭제할 수 있습니다.
- OpenAI·Claude는 브라우저 직접 호출을 막는 경우가 있습니다. 그때는 4번 자체 서버(프록시)를 쓰세요.
- 모델 이름은 제공자마다 자주 바뀝니다. 기본값(OpenAI `gpt-4o-mini`, Gemini `gemini-2.5-flash`, Claude `claude-sonnet-4-20250514`)이 거부되면(404) 발급 페이지에서 현재 이름을 확인해 고치세요.
- 연결 상태는 `Pro 연결` 화면 오른쪽에 표시됩니다(제공자·모델·마스킹된 키·보내는 주소·준비 상태).

#### 자체 서버가 받아야 하는 형식
`packages/pro-api-connector.js`(전역 `ProConnector`)의 계약을 그대로 씁니다.
요청: `POST {서버 주소}` · `Content-Type: application/json` · (토큰을 넣었다면 `Authorization: Bearer {토큰}`)

```json
{ "task": "text", "prompt": "…", "system": "…", "options": { "temperature": 0.7 }, "model": "…" }
```

응답은 아래 중 하나면 됩니다. 앱이 자동으로 글을 찾습니다.

```json
{ "text": "완성 원고" }
{ "choices": [{ "message": { "content": "완성 원고" } }] }
{ "content": [{ "type": "text", "text": "완성 원고" }] }
{ "candidates": [{ "content": { "parts": [{ "text": "완성 원고" }] } }] }
```

## 보안·한계

- 저장 위치는 `localStorage`(입력·원고)와 `sessionStorage`(Pro 설정)뿐입니다. 서버 전송은 Pro 실행 시에만 발생합니다.
- 무료 모드의 초안은 사람이 쓴 완성 원고가 아니라 **구조가 잡힌 초안**입니다. 사실·수치·후기는 사용자가 넣은 메모에만 근거합니다.
- 표시광고법·의료법 판단은 자문이 아닙니다. 최종 확인과 게시 책임은 작성자에게 있습니다.
- AI 생성 이미지는 쓰지 않습니다. 사진 위치는 가이드만 제공하며, 직접 찍은 실사를 넣는 것을 전제로 합니다.
