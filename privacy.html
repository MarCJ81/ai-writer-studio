원탭 원고 스튜디오 · 최종 갱신 2026-11-22

요약: 이 앱은 회원가입·로그인·결제가 없습니다. 주제, 경험 메모, 원고는 서버로 보내지 않고 이 브라우저 안에서만 처리됩니다. 입력과 원고는 같은 기기에서 이어 쓰도록 브라우저 저장소(localStorage)에만 남습니다. Pro API 키는 기본적으로 탭 메모리(sessionStorage)에만 두고, 창을 닫으면 사라집니다. AI 브리지에서 프롬프트를 직접 복사하거나 Pro 연결을 켜고 버튼을 누를 때만 외부로 전송됩니다.

1.수집하지 않는 것

  • 이름·전화번호·이메일 같은 계정 정보를 받지 않습니다. 계정을 만들지 않습니다.
  • 주제·경험 메모·원고를 서버에 저장하거나 분석하지 않습니다. 이 앱에는 자체 서버가 없습니다.
  • 방문 기록·광고 식별자·위치를 수집하지 않습니다. 분석 도구(애널리틱스)를 넣지 않았습니다.
  • 입력한 API 키를 개발자나 제3자에게 보내지 않습니다. 키는 요청 헤더에만 실립니다.

2.브라우저에 저장하는 것

항목목적남는 곳
주제·독자·핵심 키워드·경험 메모·제품·가격, 포맷·말투·제목 후보, 원고 본문과 첫 댓글새로고침해도 작업을 잇기 위해localStorage 키 ai-writer-studio:v1
라이트/다크 테마화면 설정 유지같은 키
Pro 제공자·모델·서버 주소·API 키같은 탭에서 이어 쓰기 위해sessionStorage 키 proconnector.config.v1 (탭을 닫으면 삭제)

저장된 내용은 브라우저 설정에서 사이트 데이터를 지우거나, Pro 화면의 연결 지우기로 삭제할 수 있습니다. 서버에 사본이 없으므로 삭제하면 복구되지 않습니다.

3.외부로 나가는 경우

아래 세 경우에만, 사용자가 직접 실행할 때 전송됩니다.

  • 무료 AI 맛보기: 무료 모드에서 무료 AI 맛보기 버튼을 누를 때만, 주제·독자·경험 메모·현재 원고가 담긴 프롬프트가 전송됩니다. 무료 체험은 Cloudflare Workers로 운영하는 무료 체험 서버를 거쳐 외부 AI 제공자(Cloudflare Workers AI, 필요하면 Google Gemini·Groq)로 전송됩니다. 서버는 프롬프트와 응답 본문을 저장하지 않고, 방문자 구분용 해시값과 그날의 사용 횟수만 남깁니다(7일 뒤 삭제). 하루 무료 횟수는 브라우저당 5회이며, 다 쓰면 안내와 함께 내 키 연결로 넘깁니다.
  • 프롬프트 복사: 아무것도 전송하지 않습니다. 사용자가 ChatGPT·Claude·Gemini 창에 직접 붙여넣습니다. 그때부터는 해당 서비스의 개인정보 처리방침이 적용됩니다.
  • Pro 연결 실행: 사용자가 제공자를 고르고 키를 넣은 뒤 버튼을 누를 때만, 프롬프트(주제·독자·경험 메모·구조 규칙·금지 목록)가 해당 제공자(OpenAI·Google·Anthropic 또는 사용자가 지정한 자체 서버)로 전송됩니다. 다듬기를 실행하면 현재 원고 본문도 함께 전송됩니다.
  • 전송 내용에 계정 정보, 연락처 목록, 다른 화면의 내용은 포함하지 않습니다.
  • 제공자에게 전송된 내용은 각 제공자의 정책에 따라 처리되며, 이 앱은 그 보관을 통제하지 않습니다.
